# Minimal Addiction Beater

<a href="https://www.youtube.com/watch?v=QmoesIWuEVo&ab_channel=Insomnes"><img width="600" alt="min_add_beater_thumbnail" src="https://github.com/user-attachments/assets/347cd3fe-d3bd-4f22-b8b2-329e8f6923b0" /></a>


Minimal Addiction beater is an application that tracks how long you've been fighting an addiction. It is intended to be clean, simple, and open-source. I stopped development early because there are better habit trackers out there and I achieved what I needed to achieve to get a hang of Flutter and mobile dev. 

## Getting Started

I never built this app so you will have to run it locally by:

1. Cloning this repository
2. Downloading the [Flutter SDK](https://docs.flutter.dev/get-started/install) and adding it to the your path
3. Running `flutter run` in the project directory

Flutter should take care of the rest. 

## Features 

To see how the app works please view the [demo video](https://www.youtube.com/watch?v=QmoesIWuEVo&ab_channel=Insomnes) linked here and above. But I've listed the features below as well:

- iSAR database to store addictions
- Add, update, reset, and delete addictions
- Two different tracking screens with linear progress bars and a github commit history style calendar
- Dark and Light mode
- Addiction hider, to hide the details of your addiction
